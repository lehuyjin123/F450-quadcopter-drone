# PROJECT PROMPT — CUSTOM STM32 + ESP32 DRONE FLIGHT CONTROLLER

## PROJECT OVERVIEW

Design and implement a custom quadcopter flight controller using:

- STM32F103C8T6 as the real-time flight controller
- ESP32-WROOM-32E as communication/UI bridge
- MPU6050 (GY-521) as IMU sensor
- 4 ESCs controlled by PWM
- WiFi communication with phone or PC
- Telemetry streaming back to UI

The project goal is:
- stable drone flight
- manual control through WiFi
- real-time telemetry monitoring
- modular architecture
- future expansion for autonomous flight/follow mode
